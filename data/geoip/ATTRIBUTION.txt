How this project uses them: offline lookups (backend/services/geoip.py) of country and autonomous system for the IP addresses in the
synthetic "rich" transaction records. Those IP addresses are randomly assigned synthetic values sampled from public ranges; they are
not observed traffic, and a lookup result says only where an address range is registered.

The databases are updated monthly by DB-IP.com. To refresh them, download the newer files and replace the two .mmdb files.
Regenerating dataset/rich/ with newer files can change which ranges exist, so the generated dataset may then differ.
